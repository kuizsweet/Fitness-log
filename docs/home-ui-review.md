# 控制台首页 UI/UX 审查与实现

日期：2026-10-15。范围：`/dashboard`，包括共用顶部导航的字号、操作尺寸和既有阴影强度。

## 结论与任务路径

首页的任务是选择日期、查看或补充当天训练和饮食，并完成签到。保留白色背景、暖色训练卡、深色彩色辅助卡和桌面三列结构；不把网页改成 iOS 系统界面。

修改前需要改进的主要问题是手机双列承载编辑内容时过窄、卡片被同一行内容拉高，以及字号和留白规则分散。修改后通过尺寸与间距表达层级，不添加信息、装饰、依赖或动画。

## 审查发现与依据

依据来自本地 `apple-design` 规范及其原始来源：

- `layout.md › Visual hierarchy`："Align elements to make them easier to scan"。应用为标题、操作和正文的稳定对齐。[Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)
- `typography.md › Conveying hierarchy`："Adjust font weight, size, and color"。应用为标题、正文、辅助信息三层排版。[Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography)
- `collections.md › Best practices`：避免观看和操作时发生难以跟踪的布局变化。窄屏三餐展开时不再突然从半宽扩为全宽。
- `buttons.md › Best practices`：为自定义按钮提供按下状态；保留可见键盘焦点，增加即时亮度反馈，不增加位移和动画。
- `accessibility.md › Vision / Mobility`：检查文字对比度、放大适应性和操作区域。[Apple Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)

以上是对网页的原则转译；没有把原生 iOS 的 pt、底部标签栏或系统窗口规则直接套到网页。

## 统一规则

| 角色               | 规则                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------- |
| 字体               | 系统字体栈；Apple 平台优先系统 SF，Windows 使用可用的 Helvetica/Arial 与中文回退，不下载字体 |
| 标题 / 正文 / 辅助 | 1.25rem / 1rem / 0.875rem；标题字重 600，其余按语义保持 400–600                              |
| 数据               | 日历日期、训练日期与签到数字使用等宽数字；签到数字保留原有更大字号                           |
| 间距               | 4/8/12/16/20/24/32px；同类标题、操作、内容使用相同间距                                       |
| 卡片               | 圆角 24px，桌面 24px 内边距，手机 20px；内容决定高度，不强制所有卡片同尺寸                   |
| 控件               | 首页按钮、下拉、备注和折叠入口至少 44px 高；普通控件圆角 12px                                |
| 导航               | 延续既有圆角导航与右侧个人账号；保持不透明白色页头；只减弱已有阴影，不增加毛玻璃             |
| 适应偏好           | 保留既有减弱透明效果回退；增加高对比度下的卡片和上传区域边界；没有新增动画                   |

布局骨架：

```text
桌面： [         日历         ][ 当天训练 ]
       [ 每日签到 ][ 三餐记录 ][ 预留卡片 ]

手机： [ 日历 ]
       [ 当天训练 ]
       [ 每日签到 ]
       [ 三餐记录 ]
       [ 预留卡片 ]
```

保留所有内容、标签、API、数据查询、表单保存、上传、签到和跳转逻辑。没有修改组件业务代码或认证逻辑，没有新增演示数据。`AuthForm.tsx` 的已有未提交改动不属于这轮修改。

- 没有完成屏幕阅读器实机审查、系统字体放大 200% 或 iPhone 真机触摸测试。日历在 320px 下单个日期格仍小于 44px 宽，以保留七日结构，但高度至少 44px。
- 继续使用既有白色页面背景和深色卡片，没有新增自动深色外观切换。
- 未提交、推送或部署这轮界面修改。
