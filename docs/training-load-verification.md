# 训练负荷：周/月双向堆叠图 · 2026-10-20

## 需求与数据边界
- 周=所选日期所在的周一至周日；月=所选日期所在的完整自然月，每柱一天。
- 上方力量按组数，下方有氧按分钟。两侧独立线性刻度，不能比较两种单位的绝对高度；不把重量、次数、RIR或分钟混成未经定义的分数。
- 颜色来自现有 NOTE_COLORS，与便签红/绿/黄/蓝保持一致。同日同色合并，多色堆叠。零值不画假条。
- 当前明确标记测试数据；fixture只在组件内计算，不调用写API、不存localStorage、不改日历/便签/真实记录。组件 entries 参数与 LoadEntry 数据接口已预留。真实业务数据接入尚未实现。

## 差异、限制与自检
保留了源的真实缓动、外框/提示卡弹簧与颜色降权，没有替换为单纯淡入淡出。业务改变包括独立有氧刻度、周/月7/28–31柱、中文提示卡宽度与双总数、现有控制台空间适配；没有声称逐像素等同原站。原站实时动效对照、真实iPhone触摸与reduced-motion系统设置尚未实测。总组数目前并非重量/次数推导出的综合负荷；是否引入更复杂权重需另定口径。


## 修订：固定视口与分类修复

本节覆盖前文中扩高卡片和页面自然撑开的布局说明。恢复 workspace height:100%、252/148/136px 最小行高、main 桌面 overflow:hidden，并移除976px最小宽度导致的横向溢出。负荷卡片不设最小高度；删除可见标题、日期/测试标签和底部说明；总数在上、单位在下，与周月控制同排。测试数据身份仍保留在辅助技术名称中。

绘图区由 ResizeObserver 读取真实宽高，按卡片剩余空间分配上下区域；最高点固定在各区域内，通过同一线性缩放压短其他柱子，分段间隙算入上限。力量/有氧各自具有独立 overflow:hidden 容器，位置不再依赖写死的127px画布高度。

10/1和10/22的错误来自旧fixture给力量便签同时填了有氧分钟；已修正为力量便签不夹带有氧，有氧独立便签。真实数据接口仍允许显式填写两种量，不按红绿蓝黄推断训练类型。
