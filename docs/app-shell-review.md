# kuizFit 业务界面视觉统一

日期：2026-10-16。范围：登录后的共享外壳及其视觉规则；沿用当前深色 Dashboard 的七卡布局。

## 发现

源码只有一个 Dashboard，并无新旧页面叠加。割裂来自外壳的两套规则：Dashboard CSS 用 body:has(.workspace) 单独覆盖背景/导航，其他页面继续继承白底及旧彩色标题；品牌只在 Dashboard 挂载，切页后消失，头部从 72px 变成约 87px。旧业务页深色控件直接落在白底上，视觉关系不一致。

用户主路径是控制台 → 训练或动作配置 → 返回控制台。导航、品牌和账号应作为稳定参照，页内内容根据任务变化，不需要为此重做功能模块或增加装饰。

## 实现

- 新增 `src/components/AppShell.module.css`：统一业务页背景 #191919、内容表面 #111111、文字 #f4f4f5、次文字 #a1a1aa 和浅蓝操作色；统一顶部 72px 导航、品牌/账号位置、标题、输入框、按钮、焦点和容器样式。使用固定视口外壳和独立 main 滚动区域，长表单不会让导航随浏览器滚动条偏移。
- 修改 `src/app/(private)/layout.tsx`：验证登录状态后用共享 shell 包住原有 header/main。认证判断保持原样。
- 修改 `src/components/AppNavigation.tsx`：品牌改为 AppBrand，在业务页持续显示；AppMain 使用共享内容样式。不更改导航目标、账号菜单、退出或业务事件。
- 修改 `src/components/dashboard/Dashboard.module.css`：将全站外壳规则移出 Dashboard 私有样式，保留网格、卡片和内部交互样式。没有新增旧布局、断点回退或第二套页面。

认证页面不处于 private 布局，不匹配 shell 作用域；未修改全局 CSS、认证组件、数据 Hook、接口、Supabase 配置或用户数据。未安装依赖。未开发移动端重排。

设计文档中的白底控制台描述已经落后于当前源码。本次以用户已确认的深色 Dashboard 和实际页面为依据，未顺带重写 PRODUCT.md / DESIGN.md。
