# kuizFit

## 功能

- **训练控制台**：训练计时、组间休息倒计时；记录动作、重量、次数、组数和 RIR，结合历史表现分析接近力竭程度。
- **智能训练计划**：支持胸＋三头、背＋二头、肩＋腿等自定义轮换；可调整训练顺序、跳过训练、增删和拖动排序动作。完成力量训练后推进计划，有氧日和休息日不推进。
- **训练物品清单**：按需添加、编辑、删除、排序和勾选物品，支持重置每日勾选状态。
- **训练月历**：按月查看力量训练、有氧、休息和签到情况；选择日期查看或新增训练记录。
- **力量进步**：按动作查看卧推、推肩等重量、次数及训练表现的历史趋势，追踪个人纪录。
- **身体目标**：设置体重和体脂率目标，查看目标进度与历史变化。
- **肌群分析**：展示单次训练计划完成度、各肌群训练组数及周期性分布。
- **每周训练负荷**：统计有效训练组数、力量训练频率和有氧时长，支持周期对比。
- **每日签到**：记录签到状态、连续签到天数及排行榜信息。
- **饮食记录**：按日期记录早餐、午餐、晚餐的照片与备注，支持历史查看。
